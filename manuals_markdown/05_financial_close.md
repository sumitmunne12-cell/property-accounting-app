Financial Close Management 

Financial Close Management simplifies your month-end and year-end close processes by reconciling work papers 

into one package that you can download and open in Excel. This application makes work paper analysis easier 

with color-coded Excel tabs and an assortment of quick reports you can run to review and account for any 

variances in your work paper balances. You can also import additional content, such as cover sheets and work 

instructions, into work paper packages for a polished presentation. Additionally, Financial Close Management 

helps facilitate the work paper review process with email notifications and status tracking, so you know when work 

papers are approved and ready to be used by your business for auditing and financial statements.

Getting Started 

Begin using Financial Close Management by logging in to the RealPage Financial Suite and accessing the Financial 

Close Management application. Add properties to the application so you can pull content into your work papers 

from subledgers associated with those properties. 

Work paper packages are collections of accounting documents that reconcile your accounts into reports for 

auditing purposes. Set up monthly and annual work paper configurations to determine which subledgers to 

provide the content for the work papers. 

After the books are closed for your properties each period (month or year), generate a preliminary package of 

work papers. Review the work papers and resolve any variances, and then generate a final package of work 

papers. Add attachments such as work instructions and cover sheets, and then submit the final work paper 

package for review. After the review process is completed, the work papers are closed for that period.

Roles and Permissions 


> **Navigation Path:** `Applications > Company > Setup > Users/Roles`


Permissions determine the specific features and activities that a user can access and the reports 

that the user can run. 

User-Based Permissions 

If you have not enabled roles in your company, then your company employs user-based 

permissions. With this permissions model, each user or user group has its own set of permissions. 

When you assign permissions to a particular user, your selections expand or limit what that user 

can see and do. 

Role-Based Permissions 

If your company enabled roles, then you use role-based permissions in your system. Using this 

permissions model, you can define a set of roles, and then assign the roles to users or user 

groups. For example, you can define an A/P Clerk role that includes permissions to enter and pay 

A/P invoices. 

Reviewing a User’s Permissions 

To review a user’s actual permissions: 

1. 
Open the Company menu, and then click the Setup tab. 

2. 
Select Users. 

3. 
Find the user, and then click the View permissions & roles link. The system opens the 

Permissions & roles report page. 

4. 
Review the user’s permissions. Optionally, click Print, and then use your printer’s dialog box 

to print the report. 

5. 
When you are finished viewing the user’s permissions report, click the Close button.

Work Paper Approval Process 

Financial Close Management helps facilitate the review process for your work papers by providing 

email notifications to reviewers and allowing you to track the status of work papers. You can also 

view the status history for work papers that are in review or completed. Use the Work papers 

page to access information about ongoing reviews or to review status history. 

There are three roles in the work paper approval process: 

• 
Preparer: This person generates the work paper package and submits it to the reviewer for 
approval. 

• 
Reviewer: This person provides the first-level review of the work paper package and submits 
it to the approver for final approval. 

• 
Approver: This person grants final approval of the work paper package. 

The reviewer and the approver can be the same person, in which case the process shortens to 

require only one approval. 

The reviewer and the approver are designated as part of the work paper configuration process. If 

necessary, a proxy reviewer can be added as an unrestricted user by an administrator. See Adding 

Unrestricted Users (on page 17) for more information.

The A/R - Commercial report displays the accounts receivables of a commercial property. The 

system uses data from the Delinquency and Prepaid report in OneSite for this report. 

A/R - Commercial Report Columns 

Accounts Receivable Summary Reconciliation 

This section analyzes the subledger and general ledger balances comparing the customer aging 

report in commercial to the General Ledger. The goal of this process is to ensure that both sets of 

records agree, providing an accurate picture of the company’s liabilities and identifying any 

discrepancies, errors, or potential fraud. When they do not, the report shows the amount of 

variance with an explanation. 

Accounts Receivable Detail Aging for Location 

This section lists all unpaid vendor invoices, broken down by vendor, invoice, and the number of 

days the debt is past due. This report helps businesses manage their cash flow by showing what is 

owed, to whom, and when payments are due, and can often be filtered to a specific location if the 

accounting system tracks expenses by location.

Configuring Financial Close Management 

Use the Configuration page to add unrestricted users and 
enable properties to be included in work papers and 
reports. Unrestricted users can approve work papers on 
another person’s behalf. You can also choose which 
properties are available in the work paper configuration. 
Only users with Limited or Full administrative privileges 
can access this page. 


> **Navigation Path:** `Applications > Financial Close Management > Setup > 
Configuration`


To access the configuration page: 

• 
From the Applications menu, select Financial close 
management, and then select the Configuration 
option on the Setup tab. The Configuration page 
opens. 
1. Select the Allow final work papers to generate 
without books being closed, Automatically 
generate close checklist, and Automatically mark 
tasks as complete when completed within 
Accounting check boxes as needed 

Tasks include Bank Reconciliation, Close Books, and 
Generate Work Papers. 

To add an unrestricted user: 

1. On the Configuration page, in the Unrestricted 
section, click the Add/Edit link. A multi-list box opens. 
2. Search for the user name you want to add from the 
Available items, either by entering the name in the 
search field or searching the list. 

If no names are listed, a Select button appears instead. 
Click the Select button to add users. 

3. Click on the user name. The user name is moved to the 
Selected items. 
4. Continue adding users until you have added all users 
that you want. Click the Done button. The multi-list box 
closes.

1. On the Configuration page, in the Entries/properties

2. Search for the entity or property you want to add from
